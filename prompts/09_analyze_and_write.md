## 分析要求

1. section_title 必须是行动标题（完整的结论性句子），禁止使用"市场概况"这类描述性标签
2. 每个 supporting_point 必须标注 confidence 和 source_urls
3. 单一来源的数据点 confidence 必须为 low
4. 优先使用经三角验证确认的数据点
5. data_visualizations 的 data 字段包含完整可渲染数据

### 深度分析框架（必须在分析和写作中体现）

根据章节主题，从以下分析维度中选择至少 3 个应用到本章节：

**定量分析维度：**
- **财务拆解**：收入结构（各业务线占比）、成本曲线（固定/变动成本拆分）、单位经济模型（单均收入 - 单均成本 = 单均利润）、盈亏平衡点估算
- **增长拆解**：增长 = 用户数 × 频次 × 客单价，分别分析各因子的驱动力和天花板
- **市场份额建模**：基于公开数据反推各玩家的 GMV/订单量/用户数，交叉验证
- **敏感性分析**：关键假设变化 ±20% 时，结论是否仍然成立

**定性分析维度：**
- **多角色视角**：不要只从平台视角分析，必须包含消费者视角、商户视角、骑手/配送员视角中的至少 1 个
- **竞争博弈推演**：如果 A 采取策略 X，B 的最优应对是什么？均衡状态是什么？
- **情景推演**：至少给出 2 个情景（乐观/悲观，或价格战持续/停止），分析各情景下的市场格局变化
- **结构性变化识别**：区分周期性变化（如价格战）和结构性变化（如技术替代），判断当前趋势的可持续性

**禁止做的事：**
- 禁止纯粹罗列数据而不解释"so what"（每个数据后面必须跟分析意义）
- 禁止只描述现状不做推演（每个章节必须包含对未来 12-24 个月的判断）
- 禁止所有论点都是同一方向（必须呈现正反两面，然后给出你的判断）

## 写作要求

**字数硬性要求：html 字段的纯文本内容（不含 HTML 标签）必须在 1500-2500 字之间。低于 1500 字视为不合格。**

1. html 字段是完整的 HTML 片段，可直接嵌入报告
2. 金字塔原理：结论先行，自上而下展开
3. 章节开头第一段就是核心结论
4. 每个段落第一句话就是该段落的论点
5. 章节标题用 `<h2>`（行动标题），子标题用 `<h3>`，每个章节至少包含 2 个 `<h3>` 子标题
6. 所有表格用 HTML `<table>` 标签，必须有 `<caption>` 和 `<div class="source-note">`
7. 禁止 Markdown 表格语法（|---|）
8. 关键数据标注置信度：`<span class="confidence high">[高置信度]</span>` / `<span class="confidence medium">[中置信度]</span>` / `<span class="confidence low">[低置信度]</span>`
9. 引用标注：`<sup>[n]</sup>`
10. 如果分析中有 data_visualizations，在 html 中生成对应的 HTML 表格
11. 每个章节至少包含 1 个 HTML 数据表格
12. 每个段落 3-5 句话，段落之间要有逻辑过渡

只输出纯 JSON，不要包含 ```json 标记，不要输出任何其他内容。
